# Guides

Task-oriented recipes. They assume you have read the
[Quickstart](../getting-started/quickstart.md) and have skimmed the
[Concepts](../concepts/index.md).

- [Coordination patterns](coordination-patterns.md): exactly-once
  dispatch, worker leases with heartbeats, cooperative cancellation,
  sweepers, and step checkpoints.
- [Lower-level API](lower-level-api.md): `Committer`, `CairnDBClient`
  with SQLAlchemy sessions, and revalidate hooks.
- [Operations](operations.md): snapshots, garbage collection, transaction
  recovery, projection rebuilds, and logging.
- [Troubleshooting](troubleshooting.md): symptoms, causes, and fixes.
